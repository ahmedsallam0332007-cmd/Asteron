# Asteron mission dataset (simulated crew, labelled SIM)

Six astronauts, 118 flight days of a 180-day mission, 14 health indicators per day, daily radiation dose,
and the on-board engine's verdict for every day. Generated by the Asteron simulator (version 1.0.0),
deterministic: the same inputs always give the same numbers.

Per-astronaut daily medical data is private and not published, so this dataset is simulated. It is anchored
to published findings: in-flight blood pressure (Norsk et al. 2015), ISS sleep (Barger et al. 2014), daily
radiation inside NASA's published ranges (NASA NTRS 20250006168), limits from NASA-STD-3001.

## Files
| File | Rows | What it holds |
|---|---|---|
| `asteron-crew-profiles.csv` | 6 | Name, role, call sign, age, sex, height, weight, nationality, specialty, prior flights, flight day, prior career dose, and each person's own normal (mean and day-to-day spread) per indicator |
| `asteron-mission-daily.csv` | 708 | One row per astronaut per day: all 14 readings, dose of the day, career dose, engine status and tier, the rules that fired, and the planned health event if any |
| `asteron-readings-long.csv` | 10,620 | One row per reading: time, indicator, value, unit, how it was measured (wearable, self-report, personal dosimeter), provenance (SIM) |
| `summary.json` | | Counts, the six planned health events, alerts and career dose per astronaut |

## How each value is measured (in a real mission)
| Indicator | Measured by |
|---|---|
| Resting heart rate, blood pressure, SpO2, temperature, sleep, exercise minutes | Wearable vital-sign garment of the CSA Bio-Monitor class (it measures heart activity, blood pressure, breathing, skin temperature, blood oxygen saturation and activity, also during sleep) |
| Mood, stress, workload, headache, rash, dizziness, vision change | Daily check-in (self-report, 1 minute) |
| Radiation dose | Personal dosimeter |

## Planned health events (to test the engine)
| Day | Astronaut | Event | Engine result |
|---|---|---|---|
| 22-24 | Okafor | Sleep loss with rising workload | watch → concern |
| 37-39 | Varga | Infection: fever with fast heart rate | watch → concern |
| 51-53 | Haddad | Blood pressure rising | watch |
| 68-70 | Rahal | Severe infection with low oxygen | watch → concern → urgent (tier 4) |
| 84-86 | Moreau | Vision change (possible SANS) | concern (from the day the symptom appears) |
| 99-101 | Sorokina | Headache with stress: check cabin CO2 | watch |

All six events are detected. On the other 690 healthy astronaut-days the engine raised a low-level "watch" twice
(0.3%) and never an alert to Earth.
